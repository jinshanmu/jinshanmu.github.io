# Shanmu Jin — Academic Homepage

Source for [jinshanmu.github.io](https://jinshanmu.github.io/), a lightweight
academic homepage highlighting:

- [CrouzeixConjecture](https://github.com/jinshanmu/CrouzeixConjecture)
- [Hatano-Nelson](https://github.com/jinshanmu/Hatano-Nelson)

The site is plain HTML and CSS, has no build step, and is published from the
root of the `main` branch with GitHub Pages.

## Figures and mathematical typography

The project figures and displayed formulas are generated by
[`scripts/generate_research_figures.py`](scripts/generate_research_figures.py).
They are derived from examples, definitions, and numerical parameters stated in
the two manuscripts.

- The Crouzeix figure uses the manuscript's sharpness example
  `N = [[0, 2], [0, 0]]`, `p(z) = z`. The unit-circle boundary is drawn from
  1,201 uniform samples of its exact parametrization.
- The Hatano-Nelson figure directly samples the least singular value of
  `z I_n - A_n(a)` for the parameters and grid recorded in
  [`assets/figure-manifest.json`](assets/figure-manifest.json). It is a
  floating-point illustration and is not used as a proof.
- Crouzeix formulas are compiled with Computer Modern, matching the fonts
  embedded in that manuscript PDF. Hatano-Nelson formulas are compiled with
  Latin Modern, matching its manuscript PDF. Formula glyphs are converted to
  paths by `dvisvgm`, so the displayed result does not depend on fonts installed
  in the reader's browser.

Regenerate the assets from the repository root:

```sh
conda run -n wirtinger_calculus \
  python scripts/generate_research_figures.py
```

The script requires NumPy, SciPy, Matplotlib, LaTeX, and `dvisvgm`; the exact
versions used for the committed assets are recorded in the manifest.
